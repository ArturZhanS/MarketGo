# Market Go

A simple online supermarket Android app built with Kotlin and Jetpack Compose.
Users can browse products, search, view categories, add items to a basket,
mark favorites, and see their purchase history.

## Author
- Iles Artur 240103183

## Main Features
- Welcome screen with Continue button
- Main screen with product grid and search (with "Not found" state)
- Category screen with 9+ categories and a category products sub-screen
- Basket with item counts, +/- buttons and total price
- Checkout screen with success state
- Favorites screen
- Profile screen with purchase history

## Tech Stack
- Kotlin, Jetpack Compose, Material 3
- MVVM architecture (ViewModel + StateFlow)
- Navigation Compose
